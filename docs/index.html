📱 手机智能体 phone-agent

零 token 本地执行的 Android 自动化智能体：任务在手机端本地规划、本地执行，不依赖云端大模型做每一步决策。开源免费，MIT 协议。

Android 8.0+无障碍 + root 双通道HTTP 远程控制热补丁
⬇ 下载最新版 APK GitHub 仓库

✨ 功能亮点

🧠 任务执行器

自然语言目标 → 本地拆解 → 逐步执行 → 监管者复核闭环

👁 视觉定位

截屏后问视觉模型拿坐标，图标按钮也能点，不靠猜

🌐 HTTP 远控

/status /screen /action /task，经 Tailscale 从云端直连操控

🔥 热补丁

dex 补丁通道，小修复不用重装，云端一键推送

⏰ 定时任务

技能卡按需注入，悬浮窗实时反馈，运行记录可导出

📦 内置 Termux

免 root 模式可用，targetSdk 28 绕开 Android 10+ 执行限制

🚀 三步用起来

下载安装：从 Releases 下载最新 phone-agent-x.xx.apk 安装

打开无障碍服务：系统设置 → 无障碍 → 开启「手机智能体」（root 设备可获得更稳的点击通道）

下达任务：在 App 里用自然语言描述目标，看它一步步执行；远控玩家可配 Tailscale 走 HTTP API

🔧 自己构建

手工编译链（aapt2 + javac + d8 + apksigner），无需 Gradle。依赖 JDK 17 与 Android SDK（build-tools 34.0.0 / android-34）：

./build.sh

版本号规则：每次迭代 +0.01（单次超 5 功能则 +0.1），versionCode +1，产物命名 phone-agent-<版本>.apk。
