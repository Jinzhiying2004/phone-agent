# 手机智能体 phone-agent

Android 自动化智能体：用自然语言下达目标，手机端本地拆解、本地执行，大模型负责规划与决策。

> 最低支持 Android 8.0（API 26），完整适配 Android 11。有 root 时执行通道更完整；
> 无 root 走无障碍通道 + 内置 Termux 免 root 模式。

## 使用逻辑

整个软件只有一个智能体（AgentLoop），三个入口共用同一套执行、记忆与经验：

1. **入口**：App 内对话 / Telegram 机器人 / HTTP 远控（经 Tailscale 从云端调用）。
2. **分流**：输入先过本地意图路由——设闹钟、倒计时、打开应用、回桌面、静音等高频指令
   在本地直接执行，不调用模型；闲聊走轻量对话回复；其余进入智能体任务流。
3. **执行循环**：智能体反复「看屏 → 决策 → 执行」——每轮截屏并读取剪枝后的控件结构，
   模型选一个工具执行（点击、视觉定位、输入、滑动、启动应用、终端、搜索、读写文件、
   调用技能卡等 21 个工具），结果回传后进入下一轮，直到目标达成或确认办不成。
   坐标按 0–1000 归一化、执行前换算真实像素；有 root 走 `input` 命令，失败回退无障碍手势；
   纯图标按钮先由视觉模型定位再点击。
4. **监管**：本地看门狗监测重复动作、双动作交替、连续失败、界面停滞等异常，
   触发后监管者看最新截图裁决（给指引继续 / 办不成中止 / 误报放行）；
   执行者报完成不算数，监管者看最终截图终审，没办到打回补做；
   没有任何成功的状态改变、又无终审背书时，禁止报完成。
5. **记忆复用**：三通道共用一份对话上下文与经验库——每次任务的结局自动沉淀，
   新任务开始前按相似度注入相关先例；办成的任务可沉淀为技能卡，
   下次关键词命中直接调用，跳过重复规划。
6. **通道差异**：只有 App 通道的任务默认在虚拟屏执行（不占用主屏，带悬浮预览），
   Telegram / 远控任务在主屏执行；远控任务结束后自动回桌面。
7. **安全**：动作按风险分四级审批（只读 / 设备控制 / 外部效应 / 破坏性）；
   远控与 Telegram 任务没有审批人在场时，「每次确认」档的动作直接拦截；
   远控服务只放行本机回环与 Tailscale 网段（100.64.0.0/10），每个请求都要 token 鉴权；
   API key 等敏感数据经 Android Keystore 加密存储。
8. **更新**：代码级小修复走 dex 热补丁（校验签名 + sha256，支持回滚）；
   涉及资源 / manifest 的变更走整包更新。

远控 API 完整说明见 [API.md](API.md)，架构说明见 [ARCHITECTURE.md](ARCHITECTURE.md)，
版本历史见 [CHANGELOG.md](CHANGELOG.md)。

## 连接你自己的 Muse

这套架构按"每人一套"设计：任何人从 GitHub 下了包，不改代码，按三步就能连上自己的 Muse。

**第 1 步：手机端准备**
- 装上 APK，打开「远控」服务
- 每台手机首次启动会自动生成自己的 token（只存在手机本地，谁也看不到）

**第 2 步：Muse 端准备**
- 自己的 Muse 通过 Tailscale 连接器加入**自己的** tailnet
- 手机装 Tailscale 登录同一账号，确认连接正常

**第 3 步：配对**
- 打开 App「云端操控」页，看到连接信息：IP、端口（v2.41 起默认 28789，可在 App 内修改）、token
- 把这三项告诉自己的 Muse，就能直连操控了

**安全说明**：远控服务只放行本机回环和 Tailscale 网段（100.64.0.0/10），
同一 WiFi 下其他设备连不上——Tailscale 是云端操控的唯一通道。
token 不要发给别人，谁拿到 token 就能操作你的手机。

## 构建

手工编译链（aapt2 + javac + d8 + apksigner），无需 Gradle / Android Studio。

依赖：JDK 17、Android SDK（含 `build-tools;34.0.0` 与 `platforms;android-34`）。

```bash
# 按 build.sh 头部的路径准备好 JDK 与 SDK（或按需修改）
./build.sh
# 产物：phone-agent-<版本号>.apk（out/ 目录）
```

构建脚本缺失 `debug.keystore` 时会自动生成调试签名。
`baselines/`（热补丁差分基线）每次构建自动归档，无需手动维护。
启动器图标以 base64 内嵌在 `tools/launcher_icons.b64.json`，构建时缺失自动还原。

## 版本号规则

- 每次迭代版本号 **+0.01**；单次迭代功能数超过 5 个则 **+0.1**
- `versionCode` 每次构建 +1（内部使用）
- 产物命名：`phone-agent-<版本号>.apk`
- 每次发版前必须按发版测试规范实测，无法真机验证的部分如实声明
