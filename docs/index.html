📱 手机智能体 phone-agent

你用一句自然语言下达目标，手机自己看屏、动手、验收，办完再向你汇报。任务在手机端本地拆解、本地执行，大模型只做规划与决策；再配合本地意图路由、技能卡复用与历史压缩，token 用量远低于全云端方案。开源免费，MIT 协议。

🎯 它能办哪些具体的事

场景你只需要说它实际会做
领权益「打开汽水音乐领免费听歌时长」启动 App → 进活动页 → 视觉定位「视频听全曲」→ 等广告播完 → 领取 → 回桌面；领到有硬停止线，不被「再看一个提前解锁」的链条一直拖下去
开关系统功能「开启个人热点」「下滑一下」「回桌面」能本地直达的零 token 直接执行；直达不了的进设置里找开关
日常代操作「打开微信给 XX 发消息说……」自己找入口、找联系人、输入、发送，全程看屏确认，不靠固定坐标死点
远程代办在 Telegram 里发一句目标手机在家里自己执行，进度实时回传到聊天里，办完发简短总结
云端操控云端 Muse 经 Tailscale 下达 goal手机端自主拆解执行，云端实时看思考、步数和日志
定时自动建每天 / 每周 / 一次性定时任务到点自动跑对应目标或技能卡，不用人在场

办不了或没办成的，它会如实报未完成和卡在哪一步，不会假装办完——有专门的完成硬门槛和监管终审拦着（见下文）。

⚙️ 它是怎么工作的

先分流：设闹钟、倒计时、打开应用、回桌面、静音这类高频指令由本地意图路由直接执行，零 token；闲聊走轻量对话；其余进智能体。

看屏决策：智能体截屏 + 读取剪枝后的控件结构，模型结合目标、记忆和技能卡决定下一步调用哪个工具（共 21 个：点击、视觉定位、输入、滑动、启动应用、终端、搜索、读写文件等）。

动手执行：坐标全程 0–1000 归一化，按真实屏尺寸换算像素；有 root 走 input 命令（毫秒级、最稳），失败回退无障碍；纯图标按钮先问视觉模型拿坐标再点。

监管验收：零 token 看门狗盯死循环和幻觉，触发后监管者看截图裁决；自称完成不算数，监管者看最终截图终审，没办到打回补做，办不到如实报未完成。

✨ 功能明细

🧠 智能体执行核心

「看屏 → 决策 → 执行 → 再看屏」的原生工具循环，会话即状态，不预生成死计划，走一步看一步、错了换方法。没有人为步数/时长上限（仅 999 轮防死循环熔断），长任务由模型自己决定何时结束。

💰 低 token 设计

  • 本地意图路由：高频指令零 token 直达
  • 技能卡复用：办成过的任务下次直接调用
  • 历史分级压缩，只保留最近轮次和最新截图
  • 截图降到 720p JPEG，控件传结构化文本

🛡 监管者防假完成

同动作重复 ≥3 次、双动作交替、连续失败 ≥4 次、反复找不存在的文字、界面停滞都会触发介入；监管者看截图裁决指引/中止/放行。领取类任务另有广告预算熔断和到账硬停止线，不会被推销链条无限拖住。

👁 视觉定位

截屏问视觉模型拿坐标，纯图标按钮也能点；坐标 0–1000 归一化，不受截图缩放影响。视觉模型不可用时降级用无障碍节点树本地找文字坐标。辅助模型分视觉/语音/图像/对话四类独立配置。

🖥 虚拟屏（仅 App 通道）

App 内任务自动在虚拟屏里跑，右上角悬浮预览实时可见，不占用主屏；Telegram / 远控任务在主屏执行。任务结束自动清理虚拟屏。需要 root，系统相机在虚拟屏不画图（MIUI 限制）。

🃏 技能卡系统

步骤 JSON 卡（固定步骤重放）和说明型卡（自然语言流程交给智能体执行）两种形态；用户手写优先于自动沉淀；支持可选步骤（失败跳过不中断）、导出/导入校验。

🧠 共享记忆与经验

三通道共用一份对话上下文（30 轮，重启不忘）和经验库（200 条）：每次任务结局自动沉淀，新任务前按相似度注入最相关的先例，先核实前提、不重复无效探索。

🔥 热补丁

dex 补丁通道，小修复不用重装；推送校验签名 + sha256，支持备份回滚。改不了 manifest / 图标 / 布局资源，那些仍走整包。

📦 内置 Termux 与保活

一键下载官方 bootstrap 并校验，免 root staging 模式可直接跑 shell。常驻三层保活：开机自启 + 10 分钟闹钟看门狗 + root 设备 Magisk 守护（60 秒查活）；手动停止会被尊重。

📡 三个入口，同一个智能体

三个入口共用同一套执行核心、技能卡、记忆和经验——谁学到的，另外两个立刻能用。

入口怎么用细节
App 内对话在「智能体」页输入目标真流式输出；运行中全屏流光边框提示（触摸穿透不挡操作）；任务中可插话反馈，下一步即参考
Telegram 机器人给自己的 Bot 发消息/status 状态、/shot 截屏、/stop 打断、/new 新对话、/task {json} 跑步骤、/agent 目标 智能执行；直接发文字＝下达目标；进度在一条消息里原地直播，只认绑定主人的消息
HTTP 远控云端经 Tailscale 调用/status、/screen（读屏零截图）、/screenshot、/action 单步、/task 目标式异步执行、/task/status 实时进度、/patch 推补丁；另有硬件/软件/系统三类直接动作

🔒 安全与限制（先说清楚）

安全

  • 动作风险四级，每级可设自动允许 / 每次确认 / 拒绝；远控与 TG 无审批人在场时，「每次确认」档直接拦截
  • 远控只放行回环和 Tailscale 网段，同 WiFi 其他设备连不上；每请求 token 鉴权
  • API key、各类 token、用户记忆走 Android Keystore 加密，不明文落盘、不进安装包

限制

  • 智能执行需要自备大模型 API key；零 token 的只有本地路由直达的几类指令
  • 无 root 只能走无障碍，MIUI 上手势偶尔被系统取消，稳定性不如 root；虚拟屏需要 root
  • 界面改版、强弹窗广告、验证码等场景可能办不成——它会如实报未完成

🚀 三步用起来

下载安装：从 Releases 下载最新 phone-agent-x.xx.apk 安装

配置模型与权限：在 App 里填主模型 API key（可从服务商拉取模型列表直接选）；开启无障碍服务，root 设备自动获得更稳的执行通道

下达任务：在 App「智能体」页用自然语言描述目标即可；想远程用就配 Telegram 机器人，或按仓库 README 的三步把自己的 Muse 经 Tailscale 连上
