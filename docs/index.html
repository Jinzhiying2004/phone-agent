⚙️ 使用逻辑

入口：整个软件只有一个智能体（AgentLoop），App 内对话、Telegram 机器人、HTTP 远控（经 Tailscale）三个入口共用同一套执行、记忆与经验。

分流：输入先过本地意图路由——设闹钟、倒计时、打开应用、回桌面、静音等高频指令在本地直接执行，不调用模型；闲聊走轻量对话回复；其余进入智能体任务流。

执行循环：智能体反复「看屏 → 决策 → 执行」：每轮截屏并读取剪枝后的控件结构，模型选一个工具执行（点击、视觉定位、输入、滑动、启动应用、终端、搜索、读写文件、调用技能卡等 21 个工具），结果回传后进入下一轮，直到目标达成或确认办不成。坐标按 0–1000 归一化、执行前换算真实像素；有 root 走 input 命令，失败回退无障碍手势；纯图标按钮先由视觉模型定位再点击。

监管：本地看门狗监测重复动作、双动作交替、连续失败、界面停滞等异常，触发后监管者看最新截图裁决（指引继续 / 办不成中止 / 误报放行）；执行者报完成不算数，监管者看最终截图终审，没办到打回补做；没有任何成功的状态改变、又无终审背书时，禁止报完成。

记忆复用：三通道共用一份对话上下文与经验库——每次任务的结局自动沉淀，新任务开始前按相似度注入相关先例；办成的任务可沉淀为技能卡，下次关键词命中直接调用，跳过重复规划。

通道差异：只有 App 通道的任务默认在虚拟屏执行（不占用主屏，带悬浮预览），Telegram / 远控任务在主屏执行；远控任务结束后自动回桌面。

安全：动作按风险分四级审批；远控与 Telegram 任务没有审批人在场时，「每次确认」档的动作直接拦截；远控服务只放行本机回环与 Tailscale 网段，每个请求都要 token 鉴权；敏感数据经 Android Keystore 加密存储。

更新：代码级小修复走 dex 热补丁（校验签名 + sha256，支持回滚）；涉及资源 / manifest 的变更走整包更新。

📡 三个入口

入口用法
App 内对话在「智能体」页输入目标；任务中可插话纠正，随时可停止
Telegram 机器人给自己的 Bot 发消息下达目标，只认绑定主人的消息；/status 状态、/shot 截屏、/stop 打断、/new 新对话
HTTP 远控云端经 Tailscale 调用 /status、/screen、/screenshot、/action、/task、/task/status、/patch

🚀 三步用起来

下载安装：从 Releases 下载最新 phone-agent-x.xx.apk 安装

配置模型与权限：在 App 里填主模型 API key；开启无障碍服务，root 设备自动获得更稳的执行通道

下达任务：在 App「智能体」页用自然语言描述目标即可；远程使用走 Telegram 机器人，或按仓库 README 的三步把自己的 Muse 经 Tailscale 连上
