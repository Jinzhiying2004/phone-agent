# 手机智能体 phone-agent

低 token 消耗的 Android 自动化智能体：任务在手机端本地拆解、本地执行，
大模型只做规划与决策，配合本地意图路由、技能卡复用与历史压缩，
token 用量远低于 OpenClaw 等全云端方案。

一句话说清它是什么：**你用一句自然语言下达目标，手机自己看屏、动手、验收，
把事情办完再向你汇报**——不用你一步步点，也不用把每一步截图都送到云端让模型看。

> 最低支持 Android 8.0（API 26），完整适配 Android 11。有 root 时能力最完整；
> 无 root 也能用（无障碍通道 + 内置 Termux 免 root 模式）。

## 它能办哪些具体的事（举例）

| 场景 | 你只需要说 | 它实际会做 |
|---|---|---|
| 领权益 | 「打开汽水音乐领免费听歌时长」 | 启动 App → 进榜单/活动页 → 用视觉定位「视频听全曲」→ 等广告播完 → 领取 → 回桌面；领到后有硬停止线，不会被「再看一个提前解锁」之类的链条一直拖下去 |
| 开关系统功能 | 「开启个人热点」「下滑一下」「回桌面」 | 能本地直达的零 token 直接执行；直达不了的交给智能体进设置里找开关 |
| 日常代操作 | 「打开微信给 XX 发消息说……」 | 自己找入口、找联系人、输入、发送，全程看屏确认，不靠固定坐标死点 |
| 远程代办 | 在 Telegram 里发一句目标 | 手机在家里自己执行，进度实时回传到聊天里，办完发简短总结 |
| 云端操控 | 云端 Muse 经 Tailscale 下达 `goal` | 手机端自主拆解执行，云端用 `/task/status` 实时看思考、步数和日志 |
| 定时自动 | 建一个每天/每周/一次性的定时任务 | 到点自动跑对应的目标或技能卡，不用人在场 |
| 终端活儿 | 「查一下这个文件/算一下/抓个网页」 | 内置 Termux / root shell 直接在手机本地执行并把输出回传 |

办不了或没办成的，它会如实报未完成和卡在哪一步，不会假装办完
（有专门的完成硬门槛和监管终审拦着，见下文）。

## 功能明细

### 1. 智能体执行核心（AgentLoop）

- 工作方式：`observe（看屏）→ 模型决策 → 调用工具执行 → 再看屏` 的原生工具循环，
  会话即状态，不预先生成死计划，走一步看一步、错了能换方法。
- 模型可用 **21 个工具**：看屏 `observe`、按文字点 `tap_text`、按坐标点 `tap`、
  视觉问答 `vision`、输入 `input`、滑动 `swipe`、返回 `back`、回桌面 `home`、
  启动应用 `launch`、等待 `sleep` / `wait_text`、调用技能卡 `use_card`、
  终端 `termux`、root shell `shell`、联网搜索 `search`、读/写文件
  `read_file` / `write_file`、抓网页 `fetch_url`、记长期记忆 `remember`、
  虚拟屏开关 `vd_start` / `vd_stop`。
- 坐标全链路 **0–1000 归一化**：模型按截图比例报数，执行前按真实屏尺寸换算像素，
  不会因为截图缩放点偏。
- 没有人为的步数/总时长上限（仅保留 999 轮防死循环熔断），长任务让模型自己决定何时结束。

### 2. 低 token 是怎么省出来的

- **本地意图路由**：设闹钟、倒计时、打开应用、回桌面、静音/震动/响铃这类高频指令
  在本地直接执行，**零 token**，不进模型。
- **闲聊分流**：打招呼、提问类消息走轻量对话回复，不进任务流烧 token；
  分流只认正向闲聊信号，短指令默认按任务处理，不会把「开启个人热点」误判成闲聊。
- **技能卡复用**：办成过的任务沉淀成技能卡，下次关键词命中直接调用，免重复规划。
- **历史压缩**：上下文分级压缩，只保留最近轮次的完整信息和最新截图。
- **截图压缩**：发给模型的截图降到 720p JPEG，控件信息传剪枝后的结构化文本。

### 3. 监管者（Supervisor）——专门防「假完成」和「打转」

- **零 token 看门狗**全程盯着：同一动作重复 ≥3 次、两个动作来回交替、
  连续失败 ≥4 次、反复找不存在的文字（疑似幻觉）、界面长时间没变化，
  任一触发就请监管者介入。
- 监管者用（可指定的）最强模型看最新截图裁决：给具体指引继续 / 判定办不成中止 /
  误报放行；有冷却和次数上限，不会无限烧 token。
- **终审**：执行者自称完成时不算数，监管者看最终截图核对目标对象状态，
  没办到打回补做（最多 2 轮）；实在办不到如实判未完成。
- **完成硬门槛**：一次成功的状态改变都没发生、又没有终审背书，禁止报完成。
- 领取类任务另有**广告预算熔断**和**到账硬停止线**：领到即收尾，
  不跟「提前解锁下一份」之类的推销链条无限看广告。

### 4. 怎么操作手机：执行通道

- **root 优先**：有 root 时点击/滑动/返回走 `input` 命令（毫秒级、最稳），
  失败再回退无障碍手势；无 root 全程走无障碍。
- **视觉定位**：纯图标、无文字的按钮先截屏问视觉模型拿坐标再点，坐标同样走
  0–1000 归一化；视觉模型不可用时降级用无障碍节点树本地找文字坐标。
- **虚拟屏**：仅 App 通道自动开——任务在虚拟屏里跑、右上角有悬浮预览，
  不占用你的主屏；Telegram / 远控任务在主屏执行。任务结束自动清理虚拟屏。

### 5. 三个入口，同一个智能体（一智能体三人格）

三个入口共用同一套 AgentLoop、技能卡、记忆和经验，谁学到的另外两个立刻能用：

| 入口 | 怎么用 | 细节 |
|---|---|---|
| **App 内对话** | 在「智能体」页输入目标 | 真流式输出（打字机效果）；任务运行时全屏流光边框提示（触摸穿透不挡操作）；可在任务中插话反馈，下一步即参考 |
| **Telegram 机器人** | 给自己的 Bot 发消息 | 指令：`/status` 状态、`/shot` 截屏、`/stop` 强行打断、`/new` 新开对话、`/task {json}` 跑步骤、`/agent 目标` 智能执行；直接发文字＝下达目标；执行进度在一条消息里原地编辑直播，结束发简短总结；只认绑定主人的消息 |
| **HTTP 远控** | 云端经 Tailscale 调用 | 接口：`/status` `/screen`（读屏，零截图）`/screenshot` `/action`（单步）`/task`（步骤式或 `goal` 目标式，默认异步）`/task/status`（实时进度）`/patch`（推热补丁）；token 鉴权 + 来源 IP 白名单。完整说明见 [API.md](API.md) |

远控另支持一批直接动作：硬件类（亮度/音量/震动/手电筒/WiFi/蓝牙/飞行模式等）、
软件类（安装/卸载/强停/清数据/应用列表）、系统类（重启/设置读写/getprop/进程管理）。

### 6. 技能卡系统

- 两种内容形态：**步骤 JSON 卡**（固定步骤重放）和**说明型卡**（自然语言流程，
  交给智能体照着执行）；两种来源：用户手写（优先级最高）和任务成功后自动沉淀。
- 触发：按关键词匹配注入，或智能体用 `use_card` 主动调用；步骤支持
  `optional: true`，可选步骤失败只跳过不中断整卡。
- 管理：技能中心可运行/删除/导出/导入（导入有格式校验和风险提示）。

### 7. 模型配置

- **主模型多档案**：可存多套服务商配置（OpenAI / DeepSeek / 智谱 / 自定义
  base_url），一键切换；配置页可从服务商拉取模型列表直接选。
- **辅助模型分四类**：视觉 / 语音 / 图像 / 对话，各自独立配置；
  视觉默认可用智谱 glm-4v-flash，主模型兜底。
- **监管者模型**：默认用最强的主模型，也可在档案上长按指定某个档案专做监管。

### 8. 记忆与沉淀（越用越顺手）

- **共享对话轮次**：三通道共用一份对话上下文（上限 30 轮，持久化，重启不忘，
  `/new` 三端一并清）。
- **共享经验库**：每次任务的结局（目标/成败/耗时/工具调用数）自动沉淀（上限 200 条），
  新任务开始前按相似度取最相关的 2 条先例注入——比如上次在某台手机上找某个
  不存在的应用白费了很久，下次会先核实前提。
- **用户长期记忆**：智能体可用 `remember` 记住你的偏好，下次直接用；
  在「我的」页可查看/删除/清空。
- **智能沉淀报告**：行为遥测按天落盘（本机保存 30 天），自动生成 1/7/30 天
  聚合报告，可一键分享给 Muse 分析改进。

### 9. 定时任务、终端与其他

- **定时任务**：每天 / 每周几 / 每隔 N 分钟 / 一次性四种类型，到点自动执行。
- **内置 Termux**：一键下载官方 bootstrap 并校验，免 root 用 staging 模式
  （targetSdk 28 绕开 Android 10+ 的 W^X 执行限制），终端页可直接交互。
- **常驻保活**：开机自启 + 闹钟看门狗（10 分钟自检）+ root 设备 Magisk 守护
  （60 秒查活）三层；你在 App 里手动「停止服务」会被尊重，不会跟你抢。
- **日志与自检**：每次任务生成带时间戳的分层日志（步骤/思考/监管），
  运行记录可导出；软件自检可记录操作与反馈；对话历史自动持久化。

### 10. 安全与审批

- **动作风险四级**：只读 / 设备控制 / 外部效应 / 破坏性，每级可设
  自动允许 / 每次确认 / 拒绝；远控和 Telegram 进来的任务没有审批人在场，
  「每次确认」档的动作会被直接拦截。
- **远控只走 Tailscale**：只放行本机回环和 Tailscale 网段（100.64.0.0/10），
  同一 WiFi 下的其他设备连不上；每个请求都要 token。
- **敏感数据加密**：API key、TG token、远控 token、用户记忆走 Android Keystore 加密存储，
  不明文落盘、不进安装包。
- **热补丁带签名**：dex 补丁通道（小修复不用重装）校验签名 + sha256，
  支持备份回滚；manifest / 资源类变更打不了补丁，仍走整包。

## 已知限制（先说清楚）

- 智能执行**需要你自备大模型 API key**（主模型必填，视觉模型建议配），
  纯本地零 token 的只有意图路由直达的那几类指令。
- 无 root 设备只能走无障碍：MIUI 等系统上无障碍手势偶尔会被系统取消，
  稳定性不如 root 通道；虚拟屏功能需要 root。
- 虚拟屏里系统相机不画图（MIUI 限制），涉及相机预览的任务请走主屏。
- 模型能力决定上限：界面改版、强弹窗广告、验证码等场景可能办不成，
  它会如实报未完成而不是假装完成。
- 热补丁只能改代码（dex），改不了图标、布局资源和 manifest。

远控 API 完整说明见 [API.md](API.md)，架构说明见 [ARCHITECTURE.md](ARCHITECTURE.md)，
版本历史见 [CHANGELOG.md](CHANGELOG.md)。

## 连接你自己的 Muse

这套架构按"每人一套"设计：任何人从 GitHub 下了包，不改代码，按三步就能连上自己的 Muse。

**第 1 步：手机端准备**
- 装上 APK，打开「远控」服务
- 每台手机首次启动会自动生成自己的 token（只存在手机本地，谁也看不到）

**第 2 步：Muse 端准备**
- 自己的 Muse 通过 Tailscale 连接器加入**自己的** tailnet
- 手机装 Tailscale 登录同一账号，确认连接正常

**第 3 步：配对**
- 打开 App「云端操控」页，看到连接信息：IP、端口（v2.41 起默认 28789，可在 App 内修改）、token
- 把这三项告诉自己的 Muse，就能直连操控了

**安全说明**：远控服务只放行本机回环和 Tailscale 网段（100.64.0.0/10），
同一 WiFi 下其他设备连不上——Tailscale 是云端操控的唯一通道。
token 不要发给别人，谁拿到 token 就能操作你的手机。

## 构建

手工编译链（aapt2 + javac + d8 + apksigner），无需 Gradle / Android Studio。

依赖：JDK 17、Android SDK（含 `build-tools;34.0.0` 与 `platforms;android-34`）。

```bash
# 按 build.sh 头部的路径准备好 JDK 与 SDK（或按需修改）
./build.sh
# 产物：phone-agent-<版本号>.apk（out/ 目录）
```

构建脚本缺失 `debug.keystore` 时会自动生成调试签名。
`baselines/`（热补丁差分基线）每次构建自动归档，无需手动维护。
启动器图标以 base64 内嵌在 `tools/launcher_icons.b64.json`，构建时缺失自动还原。

## 版本号规则

- 每次迭代版本号 **+0.01**；单次迭代功能数超过 5 个则 **+0.1**
- `versionCode` 每次构建 +1（内部使用）
- 产物命名：`phone-agent-<版本号>.apk`
- 每次发版前必须按发版测试规范实测，无法真机验证的部分如实声明
